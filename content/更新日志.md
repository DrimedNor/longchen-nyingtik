本页记录「龙的传人」网站历次版本推送的关键变更。细节从略，仅保留里程碑节点，按时间由早到晚排列。

## 2026-08-09 · 网站立项与资料初始化

- 确立网站架构：**Obsidian 写作 → 静态站生成 → GitHub Pages 托管**。
- 完成多智钦寺官网 202 篇文章批量整理入库。
- 汇编《龙钦宁提传承学习资料》电子书（229 篇，可导入微信读书）。

## 2026-08-10 ~ 08-12 · Quartz 阶段：音频与体验打磨

- 实现音频内联播放、首页自动目录树、字号调节（A−/A+，localStorage 记忆）。
- 音频播放器改造为可见播放卡片，并做适老化升级：按钮放大、±15 秒进退、倍速切换、文字状态。
- 从 Git 历史彻底移除 56.75MB 大文件，收紧仓库体积。

## 2026-08-13 · 架构切换：自研轻量静态站

- 弃用 Quartz，改用零依赖的 `build_site.py`，直接由 `content/` 生成单文件站点。
- 确定音频资源走「跳转昌列寺详情页」方案（本地仅保留少量内嵌开示）。

## 2026-08-14（上午）· 新站上线与基础能力补全

- 静态站正式上线 GitHub Pages，替代旧 Quartz 站点。
- 新增首页完整导航导览、面包屑导航、全局底部播放器。
- 配色改为藏红主色 + 浅红背景主题。

## 2026-08-14（下午）· 结构与安全优化

- 五项改进：打开次数统计（仅作者可见）、播放器快进退、侧栏仅显目录、缓冲说明、收录新开示。
- 目录层级视觉、统一序号规范、手机端菜单点击空白关闭。
- 远程推送由令牌改为 SSH，消除令牌泄露风险；新增「龙钦宁提传承」板块。
- 目录编号规则定稿：一级无编号、二级起 1/1.1、封顶 3 层。

## 2026-08-14（晚）· 藏传佛教主题整站重设计

- 配色重构为藏传佛教象征色系：深红（护法）/ 金黄（庄严）/ 绿松石（清净）/ 靛蓝（沉静）/ 奶白（慈悲）。
- 音频播放器改为默认占据下 1/3 屏，四行布局：状态栏 / 控制按钮 / 进度条 / 播放列表（默认收起）。

## 2026-08-14（本次）· 新增更新日志页与目录重排

- 新增「更新日志」独立页面（即本页），记录历次版本推送的关键变更。
- 一级目录顺序调整为：**上师开示 → 龙钦宁提传承 → 音频资料 → 书籍 → 更新日志**；侧栏与首页导览现已统一顺序。
